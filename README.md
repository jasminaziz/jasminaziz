## Jasmin Aziz

I'm a communications strategist with a decade in charity-sector communications: almost ten years at one community organisation, six of them leading brand and marketing. My strongest work is brand foundations, positioning and tone of voice. I now run that as an independent practice for values-led organisations, with AI fluency built into how I deliver.

### The Edit

[The Edit](https://theeditai.co.uk) is my opinionated directory of AI tools for comms teams in charities, cultural organisations and heritage. Every tool has been through the checks before it appears, starting with where your data sits and whether it trains on what you type. The ones that failed are published too. No sponsored listings, no affiliate links.

### Built with Claude Code

I build with Claude Code and I'm not an engineer: I write the brief and the rules, and I check every result before it goes anywhere. Most of what I build is for my own practice, so the repos here are the parts I can share.

- [The Agent Office](https://github.com/jasminaziz/agent-office): the AI agents I run my consultancy through, each at a desk with one job. Some are gates, agents whose verdict holds my work back until their condition is met. One held this repo before it went public, because the first commit still carried private details of my office. I replaced the history and ran it again before anything went out. It is a public copy with sample data.
- [Claude skills](https://github.com/jasminaziz/claude-skills): three skills I use every day, for stress-testing a plan, writing a prompt and spotting a session that has gone off course.
